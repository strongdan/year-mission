# Promotion Rule

Before promoting an item from this file into `SPEC.md`, ask:

1. Has this problem actually occurred?
2. Has it happened more than once?
3. Will this feature reduce real friction?
4. Can the Coach handle it without new UI/data structures?
5. Is there a simpler solution?
6. What existing priority will this replace?

If the answers are weak:

> Leave it here.
